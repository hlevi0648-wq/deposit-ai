# Roadmap

## Phase 1 — MVP (Weeks 1-3)
- [ ] Next.js frontend with form builder
- [ ] Fastify API skeleton
- [ ] GPT-4o integration for field extraction
- [ ] Basic routing number validation
- [ ] PDF export
- [ ] Clerk auth

## Phase 2 — Compliance (Weeks 4-6)
- [ ] NACHA rules engine
- [ ] State-specific validation
- [ ] Audit log
- [ ] Role-based access control
- [ ] Encrypted PII storage

## Phase 3 — Integrations (Weeks 7-9)
- [ ] Plaid bank API integration
- [ ] CSV export (NACHA format)
- [ ] Multi-employer support
- [ ] Bulk import (CSV, XLSX)
- [ ] Webhook notifications

## Phase 4 — Scale (Weeks 10-12)
- [ ] SOC 2 Type II readiness
- [ ] SSO (SAML)
- [ ] Custom branding for enterprises
- [ ] Analytics dashboard
- [ ] API for third-party payroll providers

## Phase 5 — Expansion
- [ ] International formats (IBAN, BIC)
- [ ] Multi-currency support
- [ ] AI fraud detection
- [ ] Marketplace for payroll providers
